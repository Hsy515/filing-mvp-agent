备案文件智能生成 MVP 数据库设计文档

版本：V1.0 | 日期：2026-05-18 | 建议数据库：PostgreSQL 或兼容关系型数据库

数据库设计以可追踪为优先原则。首版不仅要存最终结果，也要存材料、识别字段、目录匹配、AI 置信度、人工修正和复核记录，确保后续能解释结果从哪里来、是谁改过、为什么通过或退回。

1. 核心实体关系

users 1---n projects
projects 1---n materials
materials 1---n extracted_fields
projects 1---n basic_info_extract_items
projects 1---n directory_matches n---1 directory_items
projects 1---n filing_drafts 1---n draft_sections
projects 1---n review_records
projects 1---n ai_tasks
users 1---n audit_logs

2. 表结构设计

2.1 users 用户表

字段类型说明
idbigint / uuid主键
namevarchar(64)用户姓名
accountvarchar(64)登录账号，唯一
rolevarchar(32)admin、specialist、manager
statusvarchar(16)active、disabled
created_at / updated_attimestamp创建和更新时间

2.2 projects 项目表

字段类型说明
idbigint / uuid项目主键
project_namevarchar(200)项目名称
project_codevarchar(100)项目编号，同组织下唯一
procurement_methodvarchar(50)采购方式
budget_amountdecimal(14,2)预算金额，可为空
purchaser_namevarchar(200)采购人
agency_namevarchar(200)代理机构
statusvarchar(32)draft、processing、reviewing、approved、returned
directory_template_idbigint / uuid使用的备案目录模板
owner_idbigint / uuid负责人用户 ID
created_at / updated_attimestamp创建和更新时间

2.3 file_objects 文件对象表

字段类型说明
idbigint / uuid文件对象主键

字段类型说明

page_countinteger页数

created_at / updated_attimestamp创建和更新时间

2.7 directory_templates 与 directory_items 目录模板表

表关键字段说明

2.9 filing_drafts 与 draft_sections 初稿表

表关键字段说明

draft_sections id、draft_id、directory_item_id、material_id、section_order、section_title、section_status、issue_message 初稿中的每个目录段落或材料占位。

2.10 review_records 复核记录表

字段类型说明

2.11 ai_tasks 与 audit_logs 任务和日志表

4. 索引建议

表索引原因
projectsproject_code、status、owner_id项目查询和编号唯一校验。
materialsproject_id、parse_status、match_status项目工作台材料列表。
extracted_fieldsproject_id + field_key、material_id字段聚合和来源定位。
basic_info_extract_itemsproject_id + category、project_id + item_key、extract_status抓取表展示、异常筛选和人工确认。
directory_matchesproject_id + directory_item_id、material_id、match_status目录树展示和异常筛选。
filing_draftsproject_id + version_no、status初稿版本查询。
audit_logsproject_id、actor_id、created_at审计追溯。
ai_tasksproject_id、task_type、status任务进度查询。

5. 数据流向

步骤写入表说明
创建项目projects、audit_logs创建项目主记录和操作日志。
上传材料file_objects、materials、audit_logs保存文件对象和材料记录。
解析识别ai_tasks、materials、extracted_fields保存 OCR 文本、提取字段和来源。
生成基础信息抓取表basic_info_extract_items、ai_tasks按四类抓取项保存 AI 结果、来源、状态和校验结果。
人工修正字段extracted_fields、audit_logs写入 confirmed_value 和修改日志。
人工确认抓取表basic_info_extract_items、audit_logs写入 confirmed_value、状态和处理说明。
目录匹配directory_matches、ai_tasks生成每个目录项的匹配结果。
人工调整匹配directory_matches、audit_logs覆盖匹配状态和备注。
生成初稿filing_drafts、draft_sections、ai_tasks保存初稿版本和审查意见。
复核review_records、projects、filing_drafts、audit_logs记录通过或退回，更新项目和初稿状态。
