# S5 扩展路线图

首版只跑通了"把字段摆到固定表格里"的最小闭环,以下能力按优先级在后续版本补全。

## P0 - 正式上线必须

- [ ] **补全模板文件**:`templates/` 下提供 5 种表格的 .docx / .xlsx 实物,通过 S4 占位符规范扫描
- [ ] **符合性审查表字段映射**:列出符合性审查项清单(投标文件密封、签字盖章、报价规范性等),每项给"待审查"占位
- [ ] **签字位处理**:每张表的"专家签字""主任签字"位用空字符串占位,**不要**自动填名字

## P1 - 评审能力

- [ ] **评分规则注入**:支持外部传入 `scoring_rules`(技术分权重、商务分权重、价格分公式),按规则填空白格
- [ ] **得分汇总表**:专家打分由外部传入,本 Skill 只做汇总(求和、加权平均、排序)
- [ ] **多包件项目**:按 `package_id` 拆分表格,每个包件一份资格审查表 / 得分汇总表

## P2 - 开标环节

- [ ] **唱标价自动写入**:开标时主持人录入唱标价,经字段表落库后注入开标记录表
- [ ] **签到表二维码**:模板里预留二维码占位,生成时把项目 ID 编码进去
- [ ] **流标判定数据准备**:如果有效响应供应商少于 3 家,在表格里标红"是否流标"由专家勾选(不自动判)

## P3 - 流程闭环

- [ ] **评标结束回写**:专家在表格里填好结论后,反向解析回 S2 字段表(扩展字段),触发 S3 重新匹配评标报告这一目录项
- [ ] **历史项目模板复用**:同一采购单位的历史项目模板自动推荐
- [ ] **批量生成**:同一项目一键生成所有 5 张表

## 始终不做(边界)

- 自动给"通过/不通过"结论
- 自动给评分
- 自动判定流标
- 自动签名
- 修改模板本身的排版

这些必须由专家或合规经理人工完成。S5 始终只是"把数据摆到表格里"的工具。
