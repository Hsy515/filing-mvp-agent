# 占位符书写规范 (给模板设计师)

## 基本格式

只允许 `{{...}}` 双花括号格式,**不要**用 `${...}`, `{{ ... }}`(含空格),`<<...>>`(除表格锚点)。

```
{{project_name}}      ✅ 正确
{{ project_name }}    ❌ 不允许有空格
${project_name}       ❌ 不支持
<%project_name%>      ❌ 不支持
```

## 占位符类型对照

| 占位符样式 | 类型 | 渲染规则 |
|---|---|---|
| `{{name}}` | 文本 | 直接替换 |
| `{{budget}}` | 数值 | 千分位 + 两位小数 |
| `{{report_date}}` | 日期 | 按 mapping.format 渲染,默认 `YYYY-MM-DD` |
| `{{#supplier_table}}` | 表格行锚点 | 复制模板行,逐行填值 |

## 单值占位符注意事项

1. **位置**:只能放在段落文本里、表格单元格里、文本框里。不能放在样式名、字段代码、批注里。
2. **样式**:占位符所在 Run 的样式将完整保留(字体、字号、加粗、颜色)。
3. **跨 Run 风险**:如果一个占位符在 Word 里被拆成多个 Run(比如复制粘贴时格式断裂),注入器会自动合并并保留**第一个 Run** 的样式。所以请尽量**一次性输入**完整占位符,不要中间换字体后再继续。

## 表格行占位符

模板里画好表头 + 一行模板行,模板行的任一单元格里放 `{{#anchor_name}}`,其他单元格用子占位符:

| 序号 | 供应商名称 | 信用代码 | 状态 |
|---|---|---|---|
| `{{#supplier_table}}` | `{{name}}` | `{{code}}` | `{{status}}` |

数据传入:

```json
{
  "{{#supplier_table}}": {
    "type": "table_rows",
    "anchor": "supplier_table",
    "rows": [
      { "name": "A 公司", "code": "91xxx", "status": "已报名" },
      { "name": "B 公司", "code": "91yyy", "status": "已报名" }
    ]
  }
}
```

注入后:模板行被复制 N 次,模板行自身被删除。表格样式(边框、底色、字号)完整保留。

## Excel 表格锚点

xlsx 用 `<<table:anchor_name>>` 作为锚点,放表头下一行的**任意单元格**(通常 A 列)。下一行作为模板行,每列填 `{{field_name}}`:

| A | B | C |
|---|---|---|
| 序号 | 供应商名称 | 信用代码 |
| `<<table:supplier_list>>` | | |
| `{{index}}` | `{{name}}` | `{{code}}` |

## 命名约定

- 占位符名只用 `[a-z0-9_]`,小写下划线
- 名字应与 S2 字段字典里的 `item_key` 一致(便于直接映射)
- 表格锚点名用 `_list` 或 `_table` 后缀

## 模板治理

- 模板版本应与 directory_template_id 同步迭代
- 修改模板后需运行 `placeholder_scanner.py` 扫一遍,确保所有占位符在字段字典里都有对应项
- 提交模板时附带"占位符清单"(扫描结果)
