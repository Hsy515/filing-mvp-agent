# 模板设计师 Checklist

提交模板前请逐项确认:

## 占位符

- [ ] 所有占位符使用 `{{字段名}}` 格式,无空格
- [ ] 占位符名只用小写字母、数字、下划线,且与字段字典 `item_key` 对齐
- [ ] 没有出现 `${...}`、`{{ ... }}`、`<%...%>` 等非标准格式
- [ ] 没有占位符落在样式名、批注、超链接显示文本之外的位置

## 一次性输入

- [ ] 每个占位符都是一次性输入(没有"输到一半改字体再继续"导致跨 Run)
- [ ] 可用记事本/纯文本编辑器先打好,再粘贴进 Word 减少格式断裂

## 表格设计

- [ ] 重复表格画好表头 + 1 行模板行,**只有 1 行**
- [ ] 模板行第一个单元格放 `{{#anchor_name}}`
- [ ] 模板行其他单元格用子占位符 `{{field}}`(不带 #)
- [ ] xlsx 用 `<<table:anchor_name>>` 单独占一行,下一行作为模板行

## 排版

- [ ] 字体、字号、行距已经按公司公文规范设置(注入不会改这些)
- [ ] 页眉页脚里的占位符也使用相同格式
- [ ] 模板里**不要**手填示例数据(会被当成静态文本保留)

## 自检

- [ ] 用 `placeholder_scanner.py` 扫一遍,看占位符清单是否完整
- [ ] 把清单和字段字典对照,确认每个占位符在 S2 / S3 输出里都能取到值
- [ ] 把模板和一份 `placeholder_mapping_example.json` 跑一次 `inject_docx.py` 验证

## 版本管理

- [ ] 模板文件名带版本号,如 `备案文档模板_v1.2.docx`
- [ ] 模板和 `standard_directory.json` 的 template_id 同步迭代
- [ ] 旧版本归档,不要直接覆盖
