备案文件智能生成 MVP 智能体 Skill 组合设计文档

版本：V1.1 | 日期：2026-05-18 | 文档目标：把已找到的 Skill 组合成可开发、可演示的 MVP 智能体链路

本次调整后，首版 MVP 的智能体能力不再只定义为“目录匹配与初稿组装”，而是拆成一条清晰的 Skill 编排链：版面解析、基础信息抓取、目录匹配、模板注入、开评标表格生成。这样能同时覆盖图片中要求的《备案基础信息抓取表》，也能解释后续为什么可以扩展开评标表格和备案文件生成。

1. Skill 组合总览

序号Skill 名称技术选型MVP 中的职责首版状态
S1 多源文档版面分析与段落路由 Skill 可调用 TextIn 文档解析、阿里 OCR-Form、Azure Form Recognizer 等成熟产品 解析 PDF、Word、扫描件、网页截图，切分标题、正文、表格、页眉页脚，并给段落打语义标签。 首版核心
S2 备案基础信息抓取 Skill 基于大模型结构化抽取 + 规则校验 生成《备案基础信息抓取表》，覆盖文件核心信息、公告关键要素、报名信息明细、特殊备注指令。 首版新增核心
S3 备案材料目录匹配与初稿组装 Skill 大模型语义匹配 + 目录规则库 + 人工复核 把材料匹配到标准备案目录，生成缺失、待补充、待替换、异常提示，并组装备案初稿结构。 首版核心
S4 基于 Office/PDF DOM 的无损模板注入 Skill 半自研，基于 python-docx、openpyxl、Spire.Doc 等成熟底座封装 Tool 把结构化 JSON 注入标准 .docx/.xlsx 模板占位符，不改变字体、字号、页边距、表格样式等公文排版。 首版输出能力
S5 开评标表格生成 Skill 复用 S2 的字段结果和 S4 的模板注入能力 基于抓取字段和报名信息，生成资格审查表、符合性审查表、得分汇总表等开评标配套表格。 首版演示 / 后续增强

说明：S5 与原需求中的“开评标表格模板化生成”相关，复杂模板可放入下一版；但 Demo 中可以展示“可生成”的入口和样例结果，用于说明产品扩展方向。

2. Skill 编排流程

流程步骤调用 Skill输入输出人工复核点
1. 上传并解析材料 S1 版面分析 PDF、Word、扫描件、网页截图、Excel 段落、表格、标题、页码、语义标签、原文定位 识别失败或版面错乱时可重新上传或人工录入。
2. 生成基础信息抓取表 S2 基础信息抓取 S1 输出的结构化文本、表格、项目备注 《备案基础信息抓取表》、来源、状态、校验结果 缺失、异常、低置信度字段必须人工确认。
3. 目录匹配与一键归档 S3 目录匹配 确认后的抓取表、材料清单、备案目录模板 目录匹配关系、缺失项、待替换项、异常项 人工确认目录匹配，处理特殊备注指令。
4. 备案初稿生成 S3 + S4 目录匹配结果、材料引用、备案模板 可编辑备案初稿、审查意见表 合规经理复核后通过或退回。
5. 开评标表格生成 S5 + S4 报名信息明细、项目基础字段、标准表格模板 可编辑 Word/Excel 表格 首版作为演示入口，正式使用前需确认模板和规则。

3. 备案基础信息抓取表设计

抓取项具体要求输出与校验
文件核心信息 项目名称、项目编号、采购方式、预算金额、包件划分、采购内容、采购人、代理机构、公告发布时间 逐项标注来源材料、页码或段落、抓取状态、置信度；项目编号、金额、采购方式做格式校验。
公告关键要素 公告类型、报名起止时间、响应文件递交时间、开标时间、质疑投诉渠道、联系方式 对时间节点做顺序校验；联系方式缺失或格式异常时高亮。
报名信息明细 供应商名称、统一社会信用代码、报名时间、报名状态、联系方式 按供应商生成明细行；统一社会信用代码缺失、报名状态不明确时标记异常。
特殊备注指令 项目级临时 / 永久性备案特殊要求，如特定材料需额外归档、指定格式要求 进入目录匹配和初稿生成时作为约束条件；材料不足时标记待企业或人工确认。

输出结果：生成《备案基础信息抓取表》，逐条标注信息来源、抓取状态（成功 / 缺失 / 异常）、数据校验结果、异常信息高亮提醒，并支持人工修正后确认。

5. 各 Skill 输入输出

Skill输入输出失败处理
S1 版面分析 文件对象、文件类型、文件名 版面块、表格块、段落文本、语义标签 返回解析失败原因，允许人工上传更清晰材料或转人工录入。
S2 基础信息抓取 版面块、表格块、项目已知字段 基础信息抓取表 JSON 字段缺失或冲突时标记 missing / exception，不编造结果。
S3 目录匹配 确认后的抓取表、材料类型、备案目录模板 目录匹配结果、异常列表、初稿大纲 低置信度匹配进入人工确认，不直接写为最终匹配。
S4 模板注入 结构化 JSON、模板文件、占位符映射 保持原格式的 Word/Excel/PDF 输出 占位符缺失时返回错误，不强行改模板排版。
S5 开评标表格生成 报名信息明细、项目字段、表格模板 资格审查表、符合性审查表、得分汇总表等 模板或字段不足时生成待补充清单。

6. 人工复核边界

事项AI / Skill 可做人工必须做
基础信息抓取提取字段、标注来源、提示缺失和异常。确认最终值，修正企业规则未覆盖的信息。
报名明细抽取供应商名称、社会信用代码、报名时间和状态。确认报名有效性和后续是否进入评审。
特殊备注指令识别疑似特殊要求并进入提示。判断是否确认为项目约束，是否需要额外归档。
目录匹配给出匹配建议和置信度。确认低置信度项、缺失项、待替换项。
模板生成把确认后的结构化数据注入模板。确认输出文件是否符合公司公文规范和正式提交要求。

7. MVP 验收标准

验收项通过标准
Skill 链路完整能从上传材料走到基础信息抓取表、目录匹配和备案初稿。
抓取表符合图片要求四类抓取项齐全，并展示来源、状态、校验结果、异常高亮和人工确认入口。
结果可解释字段、匹配、初稿均能追溯到来源材料和处理依据。
模板不破坏格式通过 S4 输出的 Word/Excel 保留模板原有排版。
边界清楚AI 不直接给出最终合规结论，必须经过人工复核。
